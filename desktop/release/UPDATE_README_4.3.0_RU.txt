AUDIO VISUALIZER PRO — ОБНОВЛЕНИЕ {BASE_VERSION} → {VERSION}
=========================================================

ЭТО ТОЛЬКО ОБНОВЛЕНИЕ, А НЕ ПОЛНАЯ ПРОГРАММА.
Для самостоятельного запуска скачайте полный Desktop-VU ZIP.

Этот архив заменяет код приложения, сохраняя EXE, библиотеки и коллекцию
BIN из точной проверенной версии {BASE_VERSION}. Для другой базовой версии
нужен соответствующий пакет обновления либо полный ZIP.

1. Полностью закройте Audio Visualizer Pro.
2. Распакуйте обновление в отдельную папку.
3. Запустите UPDATE_PROGRAM.cmd.
4. Укажите Audio Visualizer Pro.exe из полной версии {BASE_VERSION}.
5. После сообщения об успехе запустите программу обычным способом.

Node.js и Python пользователю не требуются. Скрипт проверяет SHA-256
исходного EXE, исходного app.asar и нового кода, создаёт проверенную
резервную копию в UpdateBackup и атомарно заменяет resources\app.asar.
При отличающейся базе или запущенной программе обновление останавливается.
Автоматического завершения процесса нет. Нужны права записи в папку.

Профили, настройки входа, калибровки и BIN не удаляются. Возврат: при
закрытой программе скопируйте сохранённый старый ASAR из UpdateBackup
обратно как resources\app.asar. Сначала проверьте резервную копию.

Обновление не добавляет цифровую подпись издателя. SHA-256 подтверждает
целостность, но не заменяет Authenticode. Работа самого PowerShell-скрипта,
устройств, сна и мониторов требует проверки на Windows.

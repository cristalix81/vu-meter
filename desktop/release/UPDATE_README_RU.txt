AUDIO VISUALIZER PRO — ОБНОВЛЕНИЕ 4.2.40 → 4.2.41
================================================

В этом небольшом архиве находится новый код приложения (app.asar).
Повторно скачивать Electron, DLL и коллекцию BIN-скинов не требуется.

УСТАНОВКА ОБНОВЛЕНИЯ
1. Полностью закройте Audio Visualizer Pro.
2. Распакуйте архив обновления в отдельную папку.
3. Запустите UPDATE_PROGRAM.cmd.
4. Если появится выбор файла, укажите Audio Visualizer Pro.exe из вашей
   существующей полной версии 4.2.40.
5. После сообщения об успехе запустите программу обычным способом.

Node.js и Python для этого обновления на компьютере пользователя не нужны.
Скрипт проверяет контрольные суммы исходной версии и обновления, сохраняет
копию прежнего app.asar в UpdateBackup и заменяет код приложения.
BIN-файлы, пользовательские профили и настройки входа не удаляются.
Если программа открыта, версия отличается или проверка суммы не проходит,
обновление останавливается и сообщает причину. Автоматического завершения
процесса программы скрипт не делает.

При установке в защищённый каталог Windows потребуются права записи
в каталог приложения. Установку и удаление через NSIS следует проверять
отдельно на Windows; этот архив является обновлением portable-версии.

ВОЗВРАТ К ПРЕЖНЕЙ ВЕРСИИ
Закройте программу. Скопируйте сохранённый файл из UpdateBackup обратно
как resources\app.asar. Затем снова запустите приложение.
Не удаляйте текущий app.asar до создания и проверки его резервной копии.

ПРОВЕРКА ПОСЛЕ ОБНОВЛЕНИЯ
Выберите нужный вход, проверьте текущий скин и сохранённые профили.
Если включаете запуск при входе в Windows, проверьте его после нового входа
в систему, включая случай отсутствующего устройства или второго монитора.

Цифровая подпись издателя этим архивом не добавляется. SHA-256 подтверждает
целостность файлов, но не заменяет подпись Authenticode. Состояние реальных
устройств, сна Windows и мониторов проверяется на вашем компьютере.

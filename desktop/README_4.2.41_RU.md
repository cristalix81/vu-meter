# Audio Visualizer Pro 4.2.41

Исправления поверх предоставленной настольной версии 4.2.40. BIN-файлы,
профили и выбранные устройства сохраняются; код приложения находится в ASAR.

## Запуск отдельного прибора

1. Откройте **ВЫБОР ВХОДА**, один раз выберите нужное устройство и подключите его.
2. Откройте существующую **ДИАГНОСТИКУ**. В разделе запуска выберите монитор,
   полный экран и при необходимости «Запускать после входа в Windows».
3. Нажмите **СОХРАНИТЬ ЗАПУСК**. При следующих запусках используется этот вход
   и экран; DEMO включается только явно. Закрепите portable-папку на постоянном
   месте или используйте установленную версию.
4. Если устройство отсутствует, программа ждёт именно сохранённый вход.
   Отключённый монитор временно заменяется основным. STOP отменяет повторные
   подключения до нового явного подключения или следующего запуска программы.

Доступ к записи должен быть разрешён настройками приватности Windows.
Программа не подменяет выбранный вход другим устройством.

## Отдельная шкала каждого BIN

Выберите скин и откройте **ДИАГНОСТИКУ → КАЛИБРОВКА ШКАЛЫ**. Укажите положения
опорных отметок в процентах хода кадров отдельно для L и R. Визуальная проверка
временно показывает заданное положение стрелки и явно отмечена в диалоге.
Её закрытие возвращает реальные показания. Числа должны возрастать вместе
с уровнем; нулевую отметку нужно задавать явно.

Настройка не записывается внутрь BIN. Файл `skin-calibrations.json` хранится
в папке данных программы; экспорт JSON позволяет перенести его отдельно.
Ключ — SHA-256 содержимого, поэтому переименование BIN не сбрасывает настройку.
У исходных скинов используется их собственное соответствие кадров и уровня;
это не означает, что напечатанные художником отметки уже выровнены лабораторно.

## Проверяемая баллистика

В диагностике задаются отдельные постоянные времени VU/PPM в миллисекундах.
VU использует RMS-окно 50 мс, детектор и механическую модель стрелки; PPM —
программный квазипиковый детектор и быстрое изображение. Это настраиваемые
цифровые профили, без сертификата IEC/ANSI и без измерения true peak.

При заводских настройках и синусе 1 кГц автоматическая проверка полного пути
PCM → кадр скина при 30/60/120 Гц получила:

| Показатель | Результат |
| --- | --- |
| VU: достижение 99% установившегося положения | 319–335 мс |
| VU: возврат на 20 dB | около 367 мс |
| PPM: достижение 90% установившегося положения | 33–52 мс |
| PPM: возврат на 20 dB | 3,460–3,468 с |

Время захвата драйвером и задержка реального дисплея в эти числа не входят.
Изменение параметров меняет эти характеристики; кнопка теста подаёт измеряемый
синус со ступенями. Нажатие STOP прекращает тест без последующего автоподключения.
Стабилизация тихой стрелки меняет демпфирование, не вводя шумового порога.

## Обновление и проверка перед продажей

Малое обновление запускается через `UPDATE_PROGRAM.cmd`, проверяет SHA-256,
сохраняет резервную копию и заменяет только `resources/app.asar`.
Пользователю не нужны Node.js или Python. Полная portable-папка уже содержит
обновлённый код и исходную коллекцию 123 BIN.

Журнал: папка данных программы / `logs/application.log`.
Настройки запуска: `desktop-settings.json`. Данные пользователя при удалении
установленной версии сохраняются; собственная запись автозапуска удаляется.

Сборка установщика и автоматические проверки не заменяют испытания Windows:
нужно проверить чистую Windows 10/11, LINE IN/USB/моно/стерео, отключение и сон,
масштаб дисплеев 100/150/200%, установку, удаление и обновление. Для продажи
нужны сертификат издателя и проверка прав на распространяемые сторонние скины.
Цифровая подпись в этом выпуске не добавлялась. Старые файловые метаданные
исходного EXE сохраняются в portable; версия приложения указана в диагностике.

Исходники и инструкции воспроизводимой сборки: `README_BUILD_RU.md`.

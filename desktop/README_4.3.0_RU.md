# Audio Visualizer Pro 4.3.0

Полная настольная программа для Windows x64. Распакуйте весь ZIP в постоянную
папку и запустите **Audio Visualizer Pro.exe**. Предыдущая версия, Node.js и
Python для запуска не требуются. EXE, DLL и коллекция 123 BIN входят в полный
архив; маленький архив Update содержит только обновление кода.

## Коллекция 123 BIN-скинов

Вся исходная коллекция получает адаптивное оформление: качественное
масштабирование, мягкие отражения стекла, освещение и обработку края корпуса.
Отделка учитывает яркость, палитру, существующую рамку и тип индикатора.
Чёрные поля круглых приборов, светлые надписи и шкалы защищаются от засветки.
Внешнее освещение неподвижно и не пульсирует вместе с музыкой.

Кнопка «ОФОРМЛЕНИЕ» открывает настройки текущего прибора. Свет, стекло,
детализация и переключатель «Улучшенное оформление BIN» сохраняются отдельно
по SHA-256 содержимого каждого скина. Настройки входят в резервную копию
профиля. Отключение улучшений возвращает исходную отрисовку BIN.
Изменяется отображение: сами BIN-файлы, деления, кадры стрелок и калибровка
сохраняются. Разрешение исходного изображения ограничивает детализацию
при сильном увеличении; обработка не восстанавливает отсутствующие детали.

## Авторские приборы

В каталоге доступны четыре новых авторских оформления с непрерывно
отрисованными стрелками и векторными шкалами. Они созданы программно и не
копируют ранее присланные фотографии. Корпус, рамка, шкала, тень стрелки,
крепление и стекло отрисовываются отдельными слоями Canvas2D.

Настройка оформления позволяет подобрать свет и отражения под конкретный
экран. Настройки сохраняются. Чёткость векторной шкалы учитывает масштаб DPI;
качество исходных BIN зависит от их собственных кадров. Исходная коллекция
123 BIN остаётся доступной, а их файлы не изменяются.

Движение следует измеренному входу: режим VU использует RMS-детектор и
механическую модель, PPM — отдельный быстрый квазипиковый детектор. Отражения
и оформление не создают вымышленный аудиосигнал. Показания новых приборов
подчиняются общей настройке опорного уровня и TRIM.

## Подключение и работа

1. Откройте выбор входа, выберите аудиоустройство и подключитесь.
2. Выберите оформление в каталоге. Для спокойного отображения дайте панели
   управления скрыться; движение мыши возвращает управление.
3. В диагностике сохраните нужный монитор, полный экран и при необходимости
   запуск после входа в Windows. Автозапуск включается только явно.
4. STOP прекращает измерение и отменяет автоматическое переподключение в
   текущем сеансе. Тестовый сигнал включается только по явной команде.

При отсутствии сохранённого устройства программа ждёт именно его, а не
переключается на случайный вход. Отключённый монитор временно заменяется
основным. Для записи нужен доступ, разрешённый приватностью Windows.

## Баллистика и калибровка

Сохраняются возможности версии 4.2.41: непрерывное измерение PCM в AudioWorklet,
раздельные параметры VU/PPM, оценка нижней огибающей шума, мягкая стабилизация
тихой стрелки без жёсткого шумового порога, профили и USB-макропульт.

В диагностике для BIN задаются независимые опорные точки L/R. Настройки
хранятся отдельно в `skin-calibrations.json` и привязаны к SHA-256 содержимого
скина; переименование BIN не меняет привязку. Новые векторные приборы имеют
собственную согласованную шкалу и не используют кадры BIN.

VU/PPM описаны как настраиваемые цифровые профили, без сертификата IEC/ANSI.
Sample peak не является true peak. Измерение шума — оценка нижней огибающей
входа, а не отдельное акустическое измерение окружающей среды.

## Данные и обновление

Данные профилей и настройки находятся в пользовательской папке программы.
Журнал ошибок: `logs/application.log`. Удаление установленной версии сохраняет
пользовательские данные; собственная запись автозапуска удаляется.

Малое обновление допускается только для точной базовой версии, указанной в
его README и манифесте. Оно проверяет SHA-256, создаёт резервную копию и
атомарно заменяет `resources/app.asar`. Полный ZIP уже готов к запуску.

## Что проверяется отдельно

Выпуск сохраняет Electron 37.10.3 x64 и исходный EXE. Его старые файловые
метаданные не определяют версию кода: версия приложения указана в диагностике.
Сертификат Authenticode не предоставлен; программа не подписана этим выпуском.
SHA-256 подтверждает целостность, но не личность издателя.

Проверки JavaScript, PCM и Canvas выполняются в среде разработки. Реальная
Windows 10/11, USB/LINE IN, сон и возврат устройства, несколько мониторов,
разные DPI, установка, удаление и обновление требуют испытаний на Windows.
Они не считаются пройденными по результатам Linux/Chromium-проверок.

Для разработчика: `package-lock.json` фиксирует зависимости; `npm run check`
и `npm test` выполняют автоматические проверки. ASAR собирается без внешних
пакетов: `node tools/pack_asar.cjs pack . /путь/app.asar`. Полный portable
собирается `tools/build-portable.cjs` из проверенной базы 4.2.40 или 4.2.41.

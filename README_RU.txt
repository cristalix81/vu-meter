AV PRO — GOLD VU / BLUE PEAK / 3D WATERFALL
=========================================

Три режима по предоставленным фотографиям: золотой VU, синий пиковый
индикатор и радужный объёмный спектральный водопад в хромированном корпусе.
Чтобы увидеть новый режим, нажмите 3D WATERFALL, затем FILE или DEMO.

WINDOWS: распакуйте проект и запустите START_PROGRAM.bat.
Нужен Microsoft Edge или Google Chrome. Установка Node.js не требуется.

FILE — выбрать аудиофайл; DEMO — измеряемый тестовый сигнал без звука;
MIC — микрофон; SYSTEM — звук выбранной вкладки / экрана;
STOP — отключить источник; HOLD — заморозить изображение и историю.

1 / 2 / 3 — прибор; стрелки влево / вправо — переключение;
D — демо; S — звук системы; F — полный экран; пробел — HOLD; Esc — STOP.

Подробная инструкция, измерительная шкала и описание 3D-графики: README.md.
Опциональная сборка Electron EXE: BUILD_EXE.bat с установленным Node.js.

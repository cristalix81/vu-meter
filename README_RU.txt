ОБНОВЛЕНИЕ SA-64
================
Основная инструкция и описание измерительной шкалы: README.md.
По умолчанию теперь выбран SA-64, источник звука выключен.
Старые инструкции к архиву приведены ниже для справки.

AUDIO VISUALIZER PRO - READY EDITION 8.8
=======================================

СРАЗУ ЗАПУСТИТЬ:
  Дважды нажми START_PROGRAM.bat
  Программа откроется в отдельном окне Microsoft Edge / Google Chrome, без вкладок и адресной строки.
  Никаких дополнительных библиотек или установки Node.js для этого не нужно.
  Если Edge/Chrome нет, можно открыть index.html напрямую.

В ПРОГРАММЕ:
  LEFT / RIGHT = выбор оформления
  D = тестовые движения под DEMO-сигнал
  S = захват звука (через разрешение браузера)
  F = полноэкранный режим
  FILE = воспроизведение собственного аудиофайла

ОФОРМЛЕНИЯ:
  1. Blue Studio - синий хром, только программные стрелки
  2. Vintage Gold - золотой латунный VU
  3. Copper Valve - медный VU
  4. 3D Spectral Waterfall
  5. Dual Channel Oscilloscope
  6. Neon Spectrum

ФОТОПАНЕЛИ для VU очищены от нарисованных стрелок!
Стрелка одна и вращается кодом из центра хромированной оси.

Дополнительно:
  BUILD_EXE.bat = при желании собрать автономный Electron EXE с Node.js.
  Важно: EXE в этом ZIP НЕ содержится: здесь программа, которая уже
  запускается одним кликом с помощью установленного Edge или Chrome.

Система: Windows 10/11, рекомендовано разрешение 1920x480 (8.8-дюймовый дисплей).

МОДЫ 7-256 (250 режимов с картинки):
  Файл modes250.js. 5 коллекций по 50: классика, расширенные, креативные, премиум, лофт/ретро.
  PgUp/PgDn = +-10 режимов, Home = первый режим.
  Режимы 7-256 отрисовываются процедурно (canvas), адаптивно под 800x480 и 1920x480.

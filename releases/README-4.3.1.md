# Audio Visualizer Pro 4.3.1 · родной waterfall и коллекция BIN

Полная программа для **Windows x64** на основе исходного архива 4.3.0.

**[Скачать полный ZIP — 525 МБ](https://github.com/cristalix81/vu-meter/raw/refs/heads/main/releases/AudioVisualizerPro-Desktop-VU-4.3.1.zip)**

Распакуйте всю папку и запустите **Audio Visualizer Pro.exe**. В архив входят
EXE, библиотеки, ресурсы и все 123 BIN. Предыдущая версия, Node.js и Python
для запуска не нужны. Скачивание GitHub через **Code → Download ZIP** не
заменяет эту ссылку: большой файл программы хранится в Git LFS.

## Изменения по вашему запросу

- Родной Spectral Waterfall 4.3.0 сохранён: движок и изображение корпуса побайтно совпадают.
- Четыре встроенных стрелочных прибора Atelier убраны из каталога.
- Все **123 BIN-скина**, их миниатюры и инструменты импорта сохранены.
- Добавлены **19 визуализаций без стрелок**: семь вариантов waterfall с тем же объёмным WebGL-движком и двенадцать других спектральных и стереофонических режимов.
- Всего **143 позиции**: исходный waterfall, 19 новых режимов и 123 BIN.
- Добавлены галочки участия в автосмене. Можно смешивать встроенные режимы и BIN. Выбор сохраняется после перезапуска и в профилях.
- Исправлен редкий повторный запуск DEMO при быстром переключении режима сразу после STOP.

## Как оставить для автосмены только десять скинов

1. Откройте **Каталог приборов**.
2. В строке **Автосмена** нажмите **Снять все**.
3. Отметьте **В автосмену** у нужных десяти скинов.
4. Закройте каталог и включите обычную автосмену.

Последовательный и случайный порядок используют только отмеченные позиции.
Пустой список останавливает автосмену, а один отмеченный скин остаётся выбранным.
Галочки работают отдельно от инструментов удаления BIN. Ручной выбор любого
скина остаётся доступен. Аудиовход подключается обычным способом.

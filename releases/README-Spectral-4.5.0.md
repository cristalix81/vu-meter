# Audio Visualizer Pro — Spectral Gallery 4.5.0

Полная настольная программа Windows x64, 19 новых оформлений без стрелочных приборов. Это самостоятельная сборка, не обновление и не архив исходников.

- [Скачать установщик EXE — 199 МБ](https://github.com/cristalix81/vu-meter/raw/refs/heads/main/releases/AudioVisualizerPro-Spectral-Setup-4.5.0-x64.exe)

Закройте предыдущую версию. Распакуйте **всю** папку ZIP и запустите **Audio Visualizer Pro.exe**, либо используйте установщик. Для запуска готовой программы Node.js не нужен.

В коллекции семь Spectral Waterfall, Prism Array, Lissajous Glass, Halo Spectrum, Chromatic Ribbon, Crystal Citadel, Photon Loom, Contour Atlas, Mercury Tide, Honeycomb Resonance, Orbital Dust, Dichroic Mosaic и Resonant Membranes. Визуализация строится по аудиосигналу; STOP останавливает источник и очищает следы. Сохранены входы, калибровка, профили, пульт и выбор монитора.

Пройдены 138 автоматических тестов, 160 проверок исходного интерфейса и 54 проверки итогового app.asar в Electron 45.2.1 на Linux. Реальный запуск Windows EXE, установка/удаление и физические устройства Windows пока не проверены. Сборка не подписана сертификатом издателя. Информация о компонентах и статусе проверок включена в архив.
